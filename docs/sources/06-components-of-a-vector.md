## 1. Problem Overview
Computing the scalar component of vector $\vec{v} = 2\hat{i} - 2\hat{j} + \hat{k}$ in the direction of vector $\vec{w} = \hat{i} + \hat{j} + \hat{k}$.

---

## 2. Key Formulas and Theorems

### Scalar Component Formula
$$\text{comp}_{\vec{w}}\vec{v} = |\vec{v}| \cos\theta = \frac{\vec{v} \cdot \vec{w}}{|\vec{w}|}$$

### Dot Product Formula
$$\vec{v} \cdot \vec{w} = v_x w_x + v_y w_y + v_z w_z = (2)(1) + (-2)(1) + (1)(1) = 1$$

### Vector Length Formula
$$|\vec{w}| = \sqrt{w_x^2 + w_y^2 + w_z^2} = \sqrt{1^2 + 1^2 + 1^2} = \sqrt{3}$$

### Result
$$\text{comp}_{\vec{w}}\vec{v} = \frac{1}{\sqrt{3}}$$

## 2. Key Formulas and Theorems

### First Partials
$$f(x,y) = xy^2 + x^2 y \implies f_x = y^2 + 2xy, \quad f_y = 2xy + x^2$$

### Clairaut's Theorem (Symmetry of Mixed Partials)
$$f_{xy} = \frac{\partial}{\partial y}(y^2 + 2xy) = 2y + 2x$$
$$f_{yx} = \frac{\partial}{\partial x}(2xy + x^2) = 2y + 2x$$
$$f_{xy} = f_{yx}$$

## 1. Problem Overview
Optimizing $f(x,y,z) = x^2 + x + 2y^2 + 3z^2$ on sphere $x^2+y^2+z^2 = 1$.

---

## 2. Key Formulas and Theorems

### Lagrange System
$$\nabla f = \lambda \nabla g \implies 2x+1 = 2\lambda x, \quad 4y = 2\lambda y, \quad 6z = 2\lambda z$$
$$\text{Min} = 0 \text{ at } (-1,0,0); \quad \text{Max} = 25/8 \text{ at } (1/4, 0, \pm\sqrt{15}/4)$$

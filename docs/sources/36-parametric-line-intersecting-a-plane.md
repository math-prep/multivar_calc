## 1. Problem Overview
Intersection of line through $P_1(0,-1,1), P_2(2,3,3)$ with plane $2x + y - z = 1$.

---

## 2. Key Formulas and Theorems

### Parametric Line Equation
$$\vec{r}(t) = P_1 + t(P_2 - P_1) = \langle 2t, 4t - 1, 2t + 1 \rangle$$

### Plane Substitution
$$2(2t) + (4t - 1) - (2t + 1) = 1 \implies 6t - 2 = 1 \implies 6t = 3 \implies t = 1/2$$

### Intersection Point
$$\vec{r}(1/2) = (1, 1, 2)$$

## 1. Problem Overview
Polar double integral conversions $dA = r dr d\theta$.

---

## 2. Key Formulas and Theorems

### Evaluation
$$\int_0^{\pi/4} \int_{\sec\theta}^{2\sec\theta} \frac{r dr d\theta}{r^3} = \frac{1}{2}\int_0^{\pi/4} \cos\theta d\theta = \frac{\sqrt{2}}{4}$$

## 1. Problem Overview
Conditions for unique vs infinitely many solutions in $M\vec{x} = \vec{b}$.

---

## 2. Key Formulas and Theorems

### Invertibility Condition
$$\det(M) \neq 0 \iff c \neq 4 \implies \text{Unique Solution for all } \vec{b}$$
$$\det(M) = 0 \iff c = 4 \implies \text{Infinitely many solutions for homogeneous system } M\vec{x}=\vec{0}$$

### Non-Trivial Solution Vector
$$\vec{x} = \text{row}_1 \times \text{row}_2 = \langle 1,-1,2 \rangle \times \langle 1,-2,2 \rangle$$

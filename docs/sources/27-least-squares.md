## 1. Problem Overview
Fitting best-fit line $y = ax + b$ to points $(0,1), (2,1), (3,4)$ by minimizing $D(a,b) = \sum (y_i - (ax_i + b))^2$.

---

## 2. Key Formulas and Theorems

### Normal Equations System
$$a \sum x_i^2 + b \sum x_i = \sum x_i y_i$$
$$a \sum x_i + bn = \sum y_i$$
$$13a + 5b = 14, \quad 5a + 3b = 6 \implies a = 6/7, \quad b = 4/7$$
Best-fit line: $y = \frac{6}{7}x + \frac{4}{7}$.

## 1. Problem Overview
Solving $A\vec{x} = \vec{b}$ using matrix inversion $A^{-1}$.

---

## 2. Key Formulas and Theorems

### Matrix Inverse Formula
$$A^{-1} = \frac{1}{\det(A)} C^T$$
where $\det(A) = -10$, and $C$ is the cofactor matrix.

### Solution Formula
$$\vec{x} = A^{-1} \vec{b}$$
For $\vec{b} = \langle 0, 0, 0 \rangle$, invertibility implies unique solution $\vec{x} = \langle 0, 0, 0 \rangle$.

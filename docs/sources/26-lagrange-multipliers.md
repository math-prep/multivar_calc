## 1. Problem Overview
Maximal perimeter $P = 4x + 4y$ of rectangle inscribed in ellipse $x^2 + 4y^2 = 4$.

---

## 2. Key Formulas and Theorems

### Lagrange Multipliers
$$\nabla P = \lambda \nabla g \implies 4 = 2\lambda x, \quad 4 = 8\lambda y \implies x = 4y$$
$$(4y)^2 + 4y^2 = 4 \implies 20y^2 = 4 \implies y = 1/\sqrt{5}, \quad x = 4/\sqrt{5}$$
$$P_{\max} = 4(4/\sqrt{5}) + 4(1/\sqrt{5}) = 4\sqrt{5}$$

# Finding Area Using Cross Products

## 1. Problem Overview
Area of 3D triangle with vertices $P_1(-1,0,0), P_2(0,2,1), P_3(0,-1,1)$.

---

## 2. Key Formulas and Theorems

### Triangle Area Formula
$$\text{Area}_{\text{triangle}} = \frac{1}{2} |\vec{P_1P_2} \times \vec{P_1P_3}|$$
$$\vec{P_1P_2} = \langle 1,2,1 \rangle, \quad \vec{P_1P_3} = \langle 1,-1,1 \rangle$$
$$\vec{v}_1 \times \vec{v}_2 = \langle 3, 0, -3 \rangle \implies |\vec{v}_1 \times \vec{v}_2| = 3\sqrt{2} \implies \text{Area} = \frac{3\sqrt{2}}{2}$$

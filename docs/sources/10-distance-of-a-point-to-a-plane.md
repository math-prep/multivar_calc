## 1. Problem Overview
Calculating shortest distance from $P(0,0,0)$ to plane $2x + y - 2z = 4$.

---

## 2. Key Formulas and Theorems

### Distance via Vector Projection
$$d = \frac{|\vec{PQ} \cdot \vec{N}|}{|\vec{N}|}$$
where $\vec{N} = \langle 2, 1, -2 \rangle$, and choosing $Q(2,0,0)$ on plane:
$$d = \frac{|2(2) + 0 + 0|}{\sqrt{2^2 + 1^2 + (-2)^2}} = \frac{4}{3}$$

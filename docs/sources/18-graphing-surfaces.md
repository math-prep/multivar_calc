## 1. Problem Overview
Graphing $z = \sqrt{x^2+y^2}$ (Cone) and $z = x^2$ (Parabolic Cylinder).

---

## 2. Key Formulas and Theorems

### Cone
$$z = r = \sqrt{x^2+y^2} \quad (\text{Rotational Symmetry})$$

### Parabolic Sheet
$$z = x^2 \quad (\text{Translational Symmetry in } y)$$

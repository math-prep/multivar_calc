---

## 1. Problem Overview
Finding $b=1$ for $\vec{F} = e^{x+y}\langle x+b, x \rangle$ to be conservative, and constructing potential $f(x,y)$.

---

## 2. Key Formulas and Theorems

### Conservative Condition
$$M_y = N_x \implies e^{x+y}(x+b) = e^{x+y}(1+x) \implies b = 1$$

### Potential Function
$$f_x = e^{x+y}(x+1) \implies f(x,y) = x e^{x+y} + C$$
